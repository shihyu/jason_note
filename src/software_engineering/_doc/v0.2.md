# v0.2：TDD、競態條件與效能測試指南

## 版本目標與範圍

本版把原本簡短的 AI 時代競態測試筆記，重整成以 TDD 驅動全方位品質的實戰指南。相較 v0.1 規劃，本版新增 Node.js／JavaScript，並將內容擴展為邏輯正確性、競態條件、效能、系統／整合四大品質面向。

## 變更項目

### 新增

- 五種語言的測試工具與命令矩陣。
- Red → Green → Refactor 的完整執行流程。
- 決定性併發測試、排程探索、動態偵測與壓力測試分層。
- 效能預算、暖機、重複量測、統計與實務門檻。
- CI 分層品質閘門、flaky test 管理及完成定義。
- 官方文件與工具專案來源。

### 修改

- 將 `test.md` 改名為 `tdd-concurrency-performance-testing-guide.md`。
- 全文改為臺灣繁體中文並修正 Markdown 結構。
- 修正「GIL 可避免 Python data race」及「race detector 最精準／最強」等過度斷言。
- 更新 `src/SUMMARY.md` 的 Software Engineering 導覽。

### 移除

- 移除分隔線字元、對話式結尾、裝飾性 emoji 排名與未引用的效能數字。
- 不加入無助於技術理解的裝飾性圖片，因此本版沒有新增圖片檔案。

## 測試與驗收標準

- Markdown 標題階層、表格、清單、程式碼區塊及 reference links 可解析。
- 所有本機相對連結與 `SUMMARY.md` 目標存在。
- 五種語言、四大品質面向、TDD 流程與 CI 閘門均完整出現。
- 外部來源優先使用官方文件或工具專案原始文件。
- `test.md` 不再存在，新檔名已加入書籍導覽。

## 風險、相容性與回滾策略

- **風險**：工具旗標可能隨版本變更；文件已標示 nightly、平台及實驗性限制，採用前仍應核對專案鎖定版本。
- **相容性**：新檔名會改變直接連結；本次同步更新 `SUMMARY.md`，但外部書籤仍需另行更新。
- **內容重疊**：新指南聚焦 TDD 全方位品質；既有指南保留本機模擬與 debugger 細節，兩者互相連結。
- **回滾**：可還原 `SUMMARY.md` 項目、移除新指南，並從版本控制恢復 `test.md`；沒有資料格式或程式碼相容性影響。
