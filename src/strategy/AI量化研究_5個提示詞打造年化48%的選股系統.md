## 終極優化：發現「連續成長」的威力

### 核心洞見
> **單次創新高不夠，連續成長才是王道！**

傳統策略只看「營收年增 > 10%」這種單次條件，但用 `sustain()` 檢測連續性後，績效大幅提升。

### 優化過程

| 版本 | 條件 | CAGR | Sharpe | MDD |
|------|------|------|--------|-----|
| v1 | 連續3月>10% + 60日新高 | 42.61% | 1.55 | -31.33% |
| **v2** | **連續2月>15% + 60日新高** | **48.17%** | **1.69** | **-30.38%** |
| v3 | 連續3月>15% | 32.18% | 1.04 | -45.59% |

### 最佳組合
```
連續 2 個月營收年增 > 15% + 60 日價格新高
```

### 提示詞
```
請建立一個「連續成長」策略：
  1. 營收創 12 月新高（3 個月平均）
  2. 連續 2 個月營收年增 > 15%（關鍵！）
  3. 價格創 60 日新高（更長期的突破）
  4. 用營收成長率排序，選前 10 檔
```

## 核心洞見分析

### 傳統策略 vs 連續成長策略

| 特點 | 傳統策略 | 連續成長策略 |
|------|----------|--------------|
| 營收條件 | 單次 > 10% | 連續 2 月 > 15% |
| 價格突破 | 20 日新高 | 60 日新高 |
| 核心邏輯 | 捕捉突破 | 驗證持續性 |

### 為什麼連續性很重要？

1. **過濾假突破**：單月營收可能是一次性訂單，連續 2 個月才能確認趨勢
2. **動能延續**：連續成長的股票，動能更有可能延續
3. **減少雜訊**：`sustain()` 自動過濾掉不穩定的訊號

### 為什麼用 60 日新高？

| 期間 | 特點 |
|------|------|
| 20 日新高 | 短期波動，可能是反彈 |
| 60 日新高 | 中期突破，趨勢更確立 |

## 完整策略程式碼

```python
from finlab import data
from finlab.backtest import sim

# 取得數據
close = data.get("price:收盤價")
vol = data.get("price:成交股數") / 1000
rev = data.get("monthly_revenue:當月營收")
rev_growth = data.get("monthly_revenue:去年同月增減(%)")

# ===== 策略條件 =====

# 條件 A: 流動性篩選
vol_filter = vol.average(20) > 200

# 條件 B: 營收創新高
rev_ma3 = rev.average(3)
rev_new_high = (rev_ma3 == rev_ma3.rolling(12).max())

# 條件 C: 連續 2 個月營收年增 > 15%（核心條件！）
rev_consecutive = (rev_growth > 15).sustain(2)

# 條件 D: 價格創 60 日新高
price_60high = close == close.rolling(60).max()

# 組合所有條件
cond = rev_new_high & rev_consecutive & price_60high & vol_filter

# 用營收成長率排序，選最強的 10 檔
position = rev_growth[cond].is_largest(10)

# 對齊到月營收公布日期
position = position.reindex(rev.index_str_to_date().index, method='ffill')

# 回測
report = sim(
    position.loc["2015":],
    position_limit=0.12,
    upload=False
)

report.to_html('final_equity.html')
```

## 風險提示

本策略回測期間（2015-2025）取得 48% 年化報酬，但請注意：

- ⚠️ **最大回撤 -30.38%**：你的投資組合可能從高點下跌三成
- ⚠️ **回測限制**：未計入滑價、流動性風險、生存者偏差
- ⚠️ **過去不代表未來**：市場環境變化可能導致策略失效

## 名詞解釋

| 指標 | 中文 | 說明 | 好壞參考 |
|------|------|------|----------|
| CAGR | 年化報酬率 | 考慮複利的平均年報酬 | > 15% 為優秀 |
