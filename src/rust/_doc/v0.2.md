# v0.2：補齊 Markdown 圖形檢查範圍

## 版本目標與範圍

延續 v0.1 的對齊基線，補查帶 `plain`、`bash`、`rust` 等語言標記的 Markdown 區塊圖，以及純 ASCII 的 `+---+` 方框；將這些範圍納入可重跑的系統測試。

## 變更項目

- 修改 `tests/system/test_all_markdown_diagrams.py`，加入帶語言標記的方框圖掃描。
- 修改 `rust_locks_guide.md` 的鎖選擇流程圖，保留原有圖示並依目前終端機顯示欄寬重新調整框內空白。
- 人工核對程式片段內的選單框與純 ASCII 記憶體區塊圖；沒有發現顯示欄位偏移，因此沒有改動這些原圖。
- 沒有移除檔案或改動 Rust 程式碼。

## 測試與驗收標準

- `./test.sh`：4 個系統測試全部成功，退出碼為 0。
- 帶語言標記的方框區塊經 `align.py` 的 `analyze` 檢查；Polars 輸出表格仍以顯示欄位的幾何檢查驗證。
- `git diff --check` 無錯誤；新增測試不修改既有 Markdown 圖。

## 風險、相容性與回滾

- Polars 使用 `┆`、`╪` 的輸出仍會讓通用 `md_check.py` 誤報；幾何檢查須保留。
- 原有 emoji 圖示均保留；不同終端機對 emoji 的寬度可能不同，本版以目前 `wcwidth` 的顯示欄位為驗證基準。
- 回滾本版需還原新增的系統測試方法、`rust_locks_guide.md` 框內圖示與空白，以及此版本紀錄；v0.1 的其他修正不受影響。
